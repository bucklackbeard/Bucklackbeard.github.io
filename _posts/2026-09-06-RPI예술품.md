2022년 대학 1학년 가을에 진행한 프로젝트입니다.
예술품에 쓰이는 회로 외주 개발을 했었습니다.

## 진행 과정
* 구현목표 : 버튼 입력 시 음성파일 재생
* 고려사항 : 전시장에서 장기간 구동, 예술품 특성상 하드웨어 제한
* 개발기한 : 2일

## 회로 구성 
![회로도](/assets/images/RPI/art-map.png)
![회로사진](/assets/images/RPI/art-circuit.jpg)
* 작업은 비대면으로 진행했기에 위 사진만 보고 회로도를 구성했었습니다.
* 4개의 버튼에서 입력을 받는 구성입니다.

## 메인 코드

```python
import RPi.GPIO as GPIO
import time
import pygame

# 라즈베리파이 핀 설정
GPIO.setmode(GPIO.BCM)
GPIO.setup(17, GPIO.IN, pull_up_down =GPIO.PUD_UP)
GPIO.setup(14, GPIO.IN, pull_up_down =GPIO.PUD_UP)
GPIO.setup(9, GPIO.IN, pull_up_down =GPIO.PUD_UP)
GPIO.setup(12, GPIO.IN, pull_up_down =GPIO.PUD_UP)

# pygame 모듈 초기화
pygame.init()

try:
    while True:
        if GPIO.input(17) == False:
            print("버튼 입력 확인됨!") # 구동 테스트용 출력
            pygame.mixer.music.load("test2.mp3")
            pygame.mixer.music.play()  # 음악 파일 한번 재생
            time.sleep(1) # 오류 방지용 딜레이
        else:
            time.sleep(1)
        if GPIO.input(14) == False:
            print("버튼 입력 확인됨!")
            pygame.mixer.music.load("test1.mp3")
            pygame.mixer.music.play()  
            time.sleep(1)
        else:
            time.sleep(1)
        if GPIO.input(9) == False:
            print("버튼 입력 확인됨!")
            pygame.mixer.music.load("test3.mp3")
            pygame.mixer.music.play() 
            time.sleep(1)
        else:
            time.sleep(1)
        if GPIO.input(12) == False:
            print("버튼 입력 확인됨!")
            pygame.mixer.music.load("test4.mp3")
            pygame.mixer.music.play()  
            time.sleep(1)
        else:
            time.sleep(1)

except KeyboardInterrupt:
    GPIO.cleanup()
```

* 주석에 달아놓았듯이, 버튼 입력을 받으면 음성파일을 재생하는 단순한 구조입니다.
* 사용한 모듈은 라즈베리파이 입출력을 위한 RPI.GPIO, 재생을 위한 pygame, 지연시간을 위한 time 3가지입니다.

# 회고
지금 돌아보니 정말 엉성합니다...
아마 라즈베리파이의 처절한 성능과 긴 가동시간을 고려해서 time.sleep()로 지연을 둔 것 같은데
코드대로면 지연을 1초가 아니라 최대 4초씩 주게 됩니다.
재생하는 음성파일이 4초보다 길어서 망정이지 이거 정말 큰 실수였습니다.
상기한 내용을 발생시키는 구조 덕분에 체크도 여러번 해서 성능도 떨어지네요.
